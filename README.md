# Magia Glory — Defeat the Evil Wizard

A turn-based Python terminal game where players create a hero and battle the Evil Wizard, Kel'Thuzad.

## Features

- Five playable classes: Warrior, Mage, Archer, Paladin, and Chosen One
- Class-specific special attacks and one-use secret abilities unlocked at low health
- Randomized basic attack damage
- Healing capped at maximum health
- A menu for attacking, using abilities, healing, and viewing stats
- Wizard health regeneration and counterattacks
- Victory and defeat messages

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python3 main.py
```

Follow the prompts to name your hero, choose a class, and battle the wizard.

No external packages are required.
